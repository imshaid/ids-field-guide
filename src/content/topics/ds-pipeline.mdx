## Data science এর Venn diagram

Data science হলো **data কে কাজে লাগার মত insight এ রূপান্তরের বিজ্ঞান।** তিনটা ভিন্ন জ্ঞান মিলে এটা তৈরি:

<Diagram name="venn" caption="তিনটা বৃত্তের মাঝখানে data science; দুইটা করে মিললে অন্য জিনিস তৈরি হয়" />

- **Computer Science + Math & Statistics** = Machine Learning
- **Computer Science + Domain expertise** = Traditional software
- **Math & Statistics + Domain expertise** = Data analysis
- **তিনটাই একসাথে** = Data Science

মানে, শুধু coding বা শুধু statistics জানলে data scientist হওয়া যায় না — যে বিষয় নিয়ে কাজ (domain), সেটাও বুঝতে হয়।

## Data science pipeline

| ধাপ | কী হয় |
|---|---|
| Reality | বাস্তব জগত থেকে |
| Raw data collected | কাঁচা data সংগ্রহ |
| Data is processed | Process করা |
| Clean dataset | পরিষ্কার data |
| EDA / Models & algorithms | Explore করা, model বানানো |
| Communicate, visualize, report | ফলাফল জানানো |
| Make decisions / Data product | সিদ্ধান্ত, বা একটা data product যা আবার reality তে ফিরে যায় |

## Domain knowledge

Data science project এর প্রথম কাজ: **user ঠিক কী output চায়** সেটা জানা।

তার জন্য লাগে **business understanding আর domain knowledge** — data টা বাস্তবে কোথা থেকে আসে, কীভাবে তৈরি হয়, কীভাবে মাপা হয়, প্রতিটা attribute বা feature এর মানে কী। এই পুরো বাস্তব ধারণাটাই domain knowledge।

একটা hospital এর data তে blood sugar এর কিছু মান 600। Domain knowledge না থাকলে মনে হবে ভুল data, মুছে ফেলবে। একজন ডাক্তার জানেন — এটা সম্ভব, এরা আসলে সবচেয়ে বিপদের রোগী। ভুলে মুছে ফেললে model ঠিক সেই রোগীদেরই চিনবে না।

## Iris dataset — একটা classic উদাহরণ

Statistician আর biologist **R.A. Fisher** 1936 সালে Iris ফুলের এই dataset প্রকাশ করেন।

- **Samples** (instances, observations) — প্রতিটা row একটা ফুল; মোট **150**টা
- **Features** (attributes, measurements, dimensions) — **৪টা**: sepal length, sepal width, petal length, petal width
- **Class labels** (targets) — **৩টা** প্রজাতি: Setosa, Versicolor, Virginica

Domain knowledge এখানে মানে sepal আর petal কী, কীভাবে মাপা হয় সেটা জানা। কাজ হলো ৪টা মাপ দেখে ফুলটা কোন প্রজাতির, সেটা predict করা।
