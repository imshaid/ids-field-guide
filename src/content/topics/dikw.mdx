## Data কী

Data ছুঁয়ে দেখা যায় না, কিন্তু পৃথিবী আসলে data এর উপরেই চলছে। সহজ কথায়, **data হলো তথ্যের সবচেয়ে ছোট টুকরো।** অনেকগুলো data একসাথে করে, অর্থ যোগ করলে তৈরি হয় information।

Russell Ackoff এর সংজ্ঞাটা slide এ আছে, নিজের ভাষায়: data হলো কোনো বস্তু, ঘটনা বা পরিবেশের বৈশিষ্ট্য বোঝানোর **প্রতীক** — যা পাওয়া যায় **পর্যবেক্ষণ (observation)** থেকে।

<Idea>

**Data → (process) → Information।** "37.5" একটা data; "রোগীর জ্বর 37.5°C" হলো information।

</Idea>

## Data কোথা থেকে আসে

Data এর উৎস অনেক রকম: geographical (মানচিত্র, GPS), cultural, scientific (DNA), financial (bank), statistical (census), meteorological (আবহাওয়া), natural, transport (ট্রেনের সময়)।

## Data এর format

Slide এর ছবিটা দুইটা প্রশ্ন দিয়ে data কে চার ভাগ করে:

**গঠন কেমন?**

- **Structured** — row আর column এ সাজানো, সহজে table এ রাখা যায়: survey rating, পণ্য কেনার record, web log এর metric
- **Unstructured** — নির্দিষ্ট table নেই: email, চিঠি, audio, video, ছবি, customer comment, social media post

**কোথা থেকে?**

- **Internal** — প্রতিষ্ঠানের নিজের ভেতরের data (sales record, employee review)
- **External** — বাইরের (Facebook like, Yelp rating, tweet, Pinterest ছবি)

আরেকটা ভাগ: **human-generated** (মানুষ লিখেছে, যেমন review) আর **machine-generated** (machine নিজে তৈরি করেছে, যেমন GPS, web log)।

## DIKW Pyramid

**DIKW = Data, Information, Knowledge, Wisdom।** Pyramid টা দেখায় ছোট ছোট data কীভাবে ধাপে ধাপে সিদ্ধান্তে পৌঁছায়।

<Diagram name="dikw" caption="প্রতিটা ধাপে আগেরটার সাথে কিছু যোগ হয়: context, meaning, judgment" />

| ধাপ | মানে | Slide এর উদাহরণ |
|---|---|---|
| **Data** | কাঁচা, objective fact | 100 |
| **Information** | Data + অর্থ (processed) | 100 miles |
| **Knowledge** | Information + context, বোঝা | 100 miles অনেক দূরের পথ |
| **Wisdom** | Knowledge + insight, কী করা উচিত | 100 miles হাঁটা কঠিন, গাড়িতে যাওয়াই ভালো |

<Example title="নিজের জীবন থেকে">

CGPA sheet এ "2.9" (data) → "এই semester এ আমার GPA 2.9" (information) → "গত semester থেকে 0.5 কমেছে, math course গুলোতে বেশি কমেছে" (knowledge) → "পরের semester এ math course কম নিয়ে, আগে থেকে practice শুরু করবো" (wisdom)।

</Example>

## Data থেকে সিদ্ধান্ত

Slide এর সবুজ ছবিটা DIKW কে সময়ের সাথে মেলায়:

- **Data, information, knowledge, understanding** অতীতকে বোঝায় — কী হয়েছে (what), কীভাবে (how to), কেন (why)। এটা "doing things right"।
- **Wisdom** ভবিষ্যতের দিকে তাকায় — কোনটা সবচেয়ে ভালো (what is best)। এটা "doing the right things"।
